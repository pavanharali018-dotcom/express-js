1. What is REST?
First, understand these three terms:
- API — Application Programming Interface. It allows two applications to communicate with each other.
- REST — Representational State Transfer. It's a set of architectural principles for designing web APIs.
- REST API — An API designed using REST principles, commonly using HTTP methods such as GET, POST, PUT, PATCH, and DELETE.

REST stands for Representational State Transfer.
REST is an architectural style used to design APIs.
REST APIs allow clients and servers to communicate using HTTP.
They commonly exchange data in JSON format.
